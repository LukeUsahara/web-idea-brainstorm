# 参考事例の分析 — 流行り感・マーケの上手さ

「需要がありそうな便利ツール」ではなく、**なぜあれが刺さったか** を分解するメモ。  
完全に別の案を考えるための土台。

---

## 挙げてもらった例

### ゲーム

| 作品 | 一言 |
|------|------|
| 8番出口 | 地下通路で「異変」を探す間違い探しホラー |
| Undertale | 「誰も殺さなくていい」RPG。選択が物語を変える |
| タスクバーヒーロー | タスクバーに常駐する超小型放置RPG |
| めっちゃカメレオン | 体に絵を描いて擬態するかくれんぼ |

### ユーティリティ / プラットフォーム

| 作品 | 一言 |
|------|------|
| setlog | 1時間に1回だけ2〜4秒動画。友達と自動Vlog化 |
| note | 書く・続ける・スキで広がる。広告ない創作プラットフォーム |

---

## 共通してること（流行り感の正体）

### 1. ルールが1文で終わるが、中身がおかしい

| 例 | 1文ルール | おかしさ |
|----|-----------|----------|
| 8番出口 | 異変があったら戻る、なければ進む | 誰でも知ってる地下通路 × ホラー |
| Undertale | 誰も殺さなくていい | RPGなのに殺さない選択が本気で効く |
| めっちゃカメレオン | かくれんぼ | 体に絵を描いて擬態する |
| setlog | 1時間に1回、2〜4秒 | 加工不可・過去動画不可 |
| タスクバーヒーロー | タスクバーで放置RPG | ゲームの置き場所がおかしい |

→ **説明は簡単、でも「え、それ？」がある**

### 2. 制約が「不便」じゃなく「ネタ・体験」になってる

- setlog：編集できない → 「ありのまま」が価値
- 8番出口：操作ほぼない → 実況者も視聴者も一緒に異変探し
- Undertale：やり直しにメタな意味 → ネタバレ禁止の口コミ文化

→ **制限＝差別化**。機能を足すんじゃなく削る

### 3. 置き場所・フォーマットの意外性

- タスクバーヒーロー → **タスクバー**（ゲームじゃない場所）
- 8番出口 → **日常の地下通路**（ゲームと現実の境界が薄い）
- setlog → **毎時通知**（アプリの開き方自体がルール）
- note → **広告ないスッキリ画面**（他SNSとの対比）

→ Webでも「ブラウザのここに住む」系は未開拓かも

### 4. 結果がそのまま拡散素材になる

| 例 | 拡散されるもの |
|----|----------------|
| めっちゃカメレオン | 神擬態のスクショ・動画 |
| 8番出口 | 配信リアクション、「ここ8番出口っぽい」現実写真 |
| setlog | 分割画面Vlog、#setlog |
| Undertale | キャラ・BGM・ルート議論（ネタバレ禁止で口コミ） |

→ **作るもの＝晒すもの**。ブクマ専用サイトは弱い

### 5. 配信・友達・グループで盛り上がる設計

- 8番出口・めっちゃカメレオン：実況が拡散エンジン
- setlog：最大12人のクローズドグループ
- めっちゃカメレオン：視聴者参加型プレイ可

→ 一人で使うツールより **見せる・一緒にやる**

### 6. 既存ジャンル × 1点だけ狂ってる

| ジャンル | 狂った1点 |
|----------|-----------|
| 間違い探し | ホラー＋無限地下通路 |
| RPG | 殺さない・メタ |
| かくれんぼ | 自画自描擬態 |
| Vlog/SNS | 1時間1回・加工不可 |
| 放置RPG | タスクバー常駐 |
| ブログ | スキ文化・広告なし・書くことだけ |

→ ゼロから新ジャンルじゃなく **「〇〇だけおかしい版」**

### 7. note的な「空気」

- 始めやすい（技術不要）
- プラットフォーム内で人から人へ広がる
- 雰囲気・ブランドがある
- クリエイターが主役

→ 機能一覧じゃなく **「ここにいるとこう感じる」**

---

## 前の9案に足りなかったもの（再確認）

11・13・22 は「共感」「便利」「暇つぶし」はあるが：

- **ルールの異常さ** が弱い（大喜利は既にある）
- **置き場所の意外性** がない
- **制約がネタになってない**
- **拡散素材が設計されてない**
- **配信・グループで盛り上がる構造** が薄い

だから「流行り感が足りない」。

---

## Webに移植するときの問い

新案を出すときは、便利さより先にこれを聞く：

1. **1文で説明したとき「え？」となるか**
2. **何かを削った制約があるか**
3. **ブラウザのどこに住むか**（タブ・拡張・PWA・常駐ウィンドウ）
4. **スクショ・動画・URLを送りたくなる瞬間があるか**
5. **友達 or 配信者と一緒にやる理由があるか**
6. **既存の何の「おかしい版」か**
