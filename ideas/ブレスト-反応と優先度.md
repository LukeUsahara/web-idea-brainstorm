## tierメーカー（新規）

### コンセプト

めっちゃ簡単に tier 表（ランキング表）を作れる Web ツール。シンプルに。

### なぜアリか

- 作るのは比較的簡単（ドラッグ＆ドロップ、画像 or テキスト）
- 完成品が **そのまま画像で拡散** される（めっちゃカメレオン的な「結果が素材」）
- 「〇〇 tier list」は定期的にトレンドになる
- 専門知識不要。誰でも参加できる

### +α の方向（まだ未決）

- お題テンプレ（「人生で後悔してる食べ物 tier」など変なお題）
- 共同編集 tier（友達で1枚を奪い合い）
- 1分 tier（制約：60秒で完成させる）
- テキストだけ tier（画像不要・PC生活向け）

### 注意

- tier メーカー自体は既に多数存在 → **「一番シンプル」「一番速い」** か **おかしい制約** で差別化

## 1時間に1回・文字だけ（setlog テキスト版）— 本命寄り

### 自分の体験（一次情報）

- Instagram ストーリーより Twitter を使う理由：**ずっとPCの前**。撮るものがない。**文字でいい**
- でも Twitter も活動アカウントだと **気軽に呟く機会が減る**
- 新アカウントを作る手もある
- setlog 的に **グループで1時間に1回文字** → **進捗報告** として面白い
- ただし setlog でも近いことはできる → **+α で面白く** しないと意味がない

### setlog との差別化（+α 案）

| +α | 内容 |
|----|------|
| **文字専用** | 動画・写真なし。PCデスク民のためのサービス |
| **進捗フォーマット** | 自由投稿じゃなく「やった／やってる／詰まってる」の3択＋一言 |
| **投稿するまで他人が見えない** | BeReal 的。サボり防止＋儀式感 |
| **深夜に1本のログ** | 24投稿が時系列で1ページに自動合成（setlog の Vlog 相当） |
| **グループ全員が書かないとその時間は空白** | 進捗報告のプレッシャー／チーム感 |
| **アカウント分離不要** | 「本番Twitter」と別に、作業仲間だけの匿名グループ |
| **名前案** | desklog / typelog / 進捗log / 一行log |

### キャッチの方向

- 「撮るものがない人の setlog」
- 「1時間に1行、深夜に1日が読める」
- 「気軽に呟けない人の、気軽な部屋」

### まだ決めてないこと

- 進捗報告 **専用** に絞るか、雑談もありか
- 何人グループか（setlog は12人）
- 消えるか残るか（setlog は日次で Vlog 化。個別投稿は？）

## このUIどこがおかしい — 保留理由

- 面白いが **UIの間違い探しは専門的**（デザイン知識・画面の読み方）
- 8番出口は「誰でも知ってる地下通路」だった。UIは一般人にとって馴染みが薄いかも
- 振り替え案：「この **日常の写真** どこがおかしい」（UI じゃなく生活の異変）

---

## 描いて溶け込め — 保留

- 面白そうだが **どう作るか・どう遊ぶか** がまだ見えない
- ブラウザだと描画・マルチ・パフォーマンスの壁
- 一旦 tier / テキスト log より優先度低

---

## 今の優先度（たたき台）

1. **1時間1文字・グループ進捗 log**（+α 詰める）
2. **超シンプル tier メーカー**
3. 描いて溶け込め（様子見）
4. UI異変探し（専門的すぎ → 保留 or 日常写真版）
