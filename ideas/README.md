# アイデア文書

ブレインストーミングの成果物をここに置きます。  
このフォルダ内の `.md` は Git で管理し、GitHub 経由で PC・iPhone（Cursor PWA）のどちらからでも参照・更新できます。

## ファイルの置き方

| ファイル名の例 | 用途 |
|---------------|------|
| `2025-06-25-〇〇サイト案.md` | 日付＋テーマで1アイデア1ファイル |
| `要件メモ-〇〇.md` | 整理後の要件・方針 |
| `まとめ-制作用へ渡す.md` | 別ワークスペースに持っていく用の要約 |

## 運用のコツ

- **1テーマ1ファイル** — 後から探しやすい
- **まとめファイルを常に最新に** — 制作用ワークスペースへ渡すときは `まとめ-制作用へ渡す.md` を先に更新
- **push を忘れない** — iPhone からエージェントで書いたあとも、リモートに反映されているか確認する
- PC で続きを書く前に `git pull` する

## iPhone からの指示例

```
ideas/ に 2025-06-25-ニッチ掲示板案.md を作成して、
「地域限定の匿名掲示板」というテーマでブレストして。
箇条書きで10個出して、最後に有望そうな案を3つ選んで理由も書いて。
```

```
ideas/ 内の既存ファイルを読んで、
まとめ-制作用へ渡す.md を更新して commit & push して。
```

制作に移る前に、ここにまとめを書いて push しておくと引き継ぎが楽になります。
