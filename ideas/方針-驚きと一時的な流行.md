# 方針：驚きと一時的な流行

## やりたいこと

ありきたりな「需要がありそうなWebサイト」ではなく、

- **あっと驚く**
- **ちょっとの間だけはやりそう**

なものを作りたい。

---

## ありきたり寄り（参考まで・優先度低）

需要はありそうだが、どこかで見たことがある・量産されがちなタイプ。

| 案 | なぜありきたり寄りか |
|----|----------------------|
| 7 超短尺学習 | Duolingo・単語アプリの亜種 |
| 14 馬鹿でもわかるニュース | 要約・解説メディアは既に多い |
| 15 / 21 単機能ガチャ・代筆 | 練習向きだが差別化しにくい |
| 28 レシピ変換 | 便利ツールとして既存類似あり |

※ 捨てるわけではない。要素の借り方はあり。

---

## 「ちょっとの間だけはやる」ものの条件（たたき台）

永久サービスより、**期間限定・お題型・参加型の一発芸** を意識する。

| 条件 | 例 |
|------|-----|
| 説明が1秒で終わる | 「今日の一言を晒す」「この画像にツッコミ」 |
| 参加のハードルが極低 | ログイン不要、1行投稿だけ |
| 見る専も楽しい | 投稿しなくてもスクロールで笑える |
| お題が変わる・期限がある | 「今週のお題」「24時間で消える」 |
| 共有したくなる結果が出る | 自分の晒し・自分の点数・自分の変換結果 |
| 既存カテゴリの「変な版」 | 大喜利、掲示板、診断 — 中身が普通じゃない |

---

## 方向性メモ（次のブレスト用）

驚き・一時流行を狙うなら、次はこういう問いで練る：

1. **「それ、なに？」と言われるか** — カテゴリ名だけでは想像できない
2. **友達に送りたくなるか** — スクショ・URLを貼りたくなる瞬間があるか
3. **2週間で飽きても成功か** — 爆発的に触られて終わってもよい設計か
4. **自分が晒したくなるか** — 作者自身が使いたくなるか
