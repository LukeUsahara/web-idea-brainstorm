# まとめ：制作用ワークスペースへ渡す（画像圧縮ツール）

> 最終更新: 2025-06-25  
> 新規レポジトリで実装開始用の要約。

---

## 作るもの

**TinyPNG 上位互換の画像圧縮 Web ツール**

- 枚数・月間制限なし
- 画像は **ブラウザ内だけ** で処理（WASM）。サーバーに送らない
- JPEG / PNG 圧縮、複数枚、ZIP 一括 DL
- 日本語 UI

## 詳細計画

→ **`計画-画像圧縮-TinyPNG上位互換.md`** を読むこと

## 技術（推奨）

- Vite + TypeScript（React なしで可）
- `@jsquash/jpeg` + `@jsquash/oxipng`
- Web Worker + JSZip
- Cloudflare Pages / GitHub Pages（静的のみ）

## MVP の Done

- 10枚連続圧縮、外部 POST なし、ZIP DL、スマホ可、HTTPS 公開
