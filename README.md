# Web制作アイデア捻出

このワークスペースは **制作用ではなく、アイデア出し専用** の場所です。

## このワークスペースの目的

Web制作のアイデアをブレインストーミングし、AI と対話しながら方向性を固めるためのワークスペースです。  
ここでは実装や本番用のコード制作は行いません。

## 推奨ワークフロー

1. **ブレインストーミング**  
   このワークスペース（または iPhone から Cursor PWA）で AI と対話し、アイデア・要件・方針を出す。

2. **まとめ**  
   対話の結果を AI に整理・要約してもらう（企画メモ、要件一覧、画面構成のたたき台など）。  
   成果物は `ideas/` 以下の Markdown に保存する。

3. **GitHub に反映**  
   まとめた内容を commit / push し、リモートと同期する。

4. **別ワークスペースへ移動**  
   まとめた内容を持って、制作用の別ワークスペースに移る。

5. **制作**  
   制作用ワークスペースで、まとめた内容を伝えて実装を進める。

## Git 運用

このワークスペースは **Git + GitHub で管理** しています。  
iPhone から Cursor の Cloud Agent（PWA）で操作するためにも、リポジトリをリモートに置く運用です。

| 項目 | 内容 |
|------|------|
| リモート | `https://github.com/LukeUsahara/web-idea-brainstorm.git` |
| ブランチ | `main` |
| 管理対象 | `README.md`、`ideas/` 以下の Markdown 文書 |

### 基本的な Git 操作（PC）

```powershell
cd "L:\開発\Web制作アイデア捻出"

# 最新を取得
git pull

# 変更を保存
git add .
git commit -m "ideas: 〇〇案を追加"
git push
```

### コミットの目安

- ブレインストーミングのたびに、または1テーマごとに commit する
- コミットメッセージは内容がわかる短い日本語でよい（例: `ideas: ニッチ掲示板案を追加`）
- 制作用へ渡す前に `ideas/まとめ-制作用へ渡す.md` を更新して push しておく

### AI による commit & push

このワークスペースでは、AI が文書を更新したあと **確認なしで commit & push してよい** 運用とする。  
（`.cursor/rules/git-auto-commit.mdc` にも記載）

## iPhone からの操作（Cursor PWA）

1. iPhone の Safari で [cursor.com/agents](https://cursor.com/agents) を開く
2. 共有ボタン → **ホーム画面に追加**（PWA として使う）
3. Cursor アカウントでログイン
4. このリポジトリ（`LukeUsahara/web-idea-brainstorm`）を指定してエージェントを起動
5. 例えば次のように指示する:
   - 「`ideas/` に `2025-06-25-〇〇案.md` を新規作成して、このテーマでブレストして」
   - 「今日の対話を `ideas/まとめ-制作用へ渡す.md` に整理して commit して」

PWA からは **指示・確認・承認** が中心。md の生成や commit はエージェントに任せる想定です。

## このワークスペースに置くもの

- `README.md`（このファイル）— ワークスペースの説明
- `ideas/` — アイデア・企画に関する Markdown 文書（`.md`）
- ブレインストーミングの成果物、要件メモ、制作用ワークスペースへ渡すまとめ

## このワークスペースに置かないもの

- HTML / CSS / JavaScript などの実装ファイル
- 本番用のコード、ビルド成果物
- 認証情報（`.env`、API キーなど）

## 注意

- このワークスペースに置かれたファイルは、試作・メモ・議論用であり、本番成果物とは限りません。
- 実装に入るタイミングで、必ず制作用ワークスペースに切り替えてください。
- リポジトリは **private 推奨**（アイデアメモが含まれるため）。
- PC で作業したあとは `git pull`、iPhone / クラウドで更新したあとは PC で `git pull` してから続ける。
