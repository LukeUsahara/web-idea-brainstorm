# Web制作アイデア捻出

このワークスペースは **制作用ではなく、アイデア出し専用** の場所です。

## このワークスペースの目的

Web制作のアイデアをブレインストーミングし、AI と対話しながら方向性を固めるためのワークスペースです。  
ここでは実装や本番用のコード制作は行いません。

## 推奨ワークフロー

1. **ブレインストーミング**  
   このワークスペースで AI と対話し、アイデア・要件・方針を出す。

2. **まとめ**  
   対話の結果を AI に整理・要約してもらう（企画メモ、要件一覧、画面構成のたたき台など）。

3. **別ワークスペースへ移動**  
   まとめた内容を持って、制作用の別ワークスペースに移る。

4. **制作**  
   制作用ワークスペースで、まとめた内容を伝えて実装を進める。

## このワークスペースに置くもの

- `README.md`（このファイル）— ワークスペースの説明
- `ideas/` — アイデア・企画に関する Markdown 文書（`.md`）
- ブレインストーミングの成果物、要件メモ、制作用ワークスペースへ渡すまとめ

## 注意

- このワークスペースに置かれたファイルは、試作・メモ・議論用であり、本番成果物とは限りません。
- HTML / CSS / JavaScript などの実装ファイルは、制作用ワークスペースで扱ってください。
- 実装に入るタイミングで、必ず制作用ワークスペースに切り替えてください。
